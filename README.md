# Mero Hisab — Personal Expense Tracker

A simple React personal expense tracker built for a college React assignment.

## Required features
- Add income and expense transactions with amount, category, description, and date.
- Running balance = income - expenses.
- Transaction list with individual delete.
- Filter by category/type and sort by date.
- Data persistence using localStorage.
- Light/dark mode.

## Stretch goals
- Spending chart by category.
- Monthly summary.
- Monthly budget with warning when exceeded.

## Run
```bash
npm install
npm run dev
```


## Main packages used

- **Tailwind CSS** + `@tailwindcss/vite` for utility-based styling.
- **React Toastify** for simple success/delete notifications.
- **Recharts** for the spending-by-category chart.
